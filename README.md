# 🏡 Conecta Hogar - Monorepo

Repositorio unificado que integra la arquitectura completa del sistema Conecta Hogar.

## 📁 Estructura del Proyecto

- `backend/`: API y servicios del sistema (Node.js / Express).
- `frontend/`: Interfaz web de usuario (React + TypeScript).

## 🚀 Inicio Rápido

### Backend
```bash
cd backend
npm install
npm run dev

### Frontend
```bash
cd frontend
npm install
npm run dev
